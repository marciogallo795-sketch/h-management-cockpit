# H! Management Cockpit — V2 Simplificado

Arquitetura de jornada única:

S0 Radar → S1 Qualificada → S2 Discovery → S3 Proposta → S4 Commit → S5 Backlog → S6 Delivery → S7 Expand

Cada oportunidade/projeto é um único registro. Ao mudar a etapa, novos campos aparecem e os dados anteriores permanecem.

## Publicação
Substitua no GitHub os arquivos:
- index.html
- styles.css
- app.js
- data.js

Se o GitHub Pages já estiver ativo, basta fazer commit e aguardar a atualização.

Os dados ficam no navegador via LocalStorage. Use Exportar backup regularmente.
